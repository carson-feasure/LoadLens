# LoadLens two-minute demo

1. Start on **Overview**. Point out the two derived summaries: 240 semester study hrs and the 23-hrs Week 7 peak. Explain that this single page now combines the former Dashboard and Overview experiences.

2. In **Combined workload**, show the always-visible color legend with both course codes and full titles. Select the prominent **Week 7 · 23 hrs** above-limit control. In **Why this week is high**, show the explicit **ABOVE LIMIT** state and the COG 107 Midterm, kind, due date, recurring workload, and extra assessment hours.

3. Briefly switch the schedule card between **Day**, **Week**, and **Semester**. Explain that due dates are deadline markers while the workload is distributed across the week. Note that the separate upcoming-deadlines block is gone because selected-week deadlines now live in the breakdown.

4. Open **Build / Edit my semester**. Show that catalog cards include meeting pattern, description, group, workload level, average hrs/week, and demo interest tags. Use **Major / interest (demo)** to filter by `Environment`, then **Clear**. Explain that these are illustrative interests, not verified degree requirements.

5. In **My courses**, open COG 107 and show that its Workload tab is a selectable 15-week workload/deadline list rather than another graph. Open **Syllabus**, choose **Upload Syllabus**, and show the parsed course match, week-by-week topics/readings/assignments, and expandable JSON. Explain that the file is sent through the server, while only parsed JSON is retained in this browser.

6. Choose **Adjust my courses**. The prepared example is labeled `WRIT 150 → ISE 105` without claiming equivalence. Compare 16 versus 16 units, 23 versus 17 peak hrs, three versus zero above-limit weeks, and 240 versus 194 semester hrs. Demonstrate **Keep current** or **Use new schedule**; either outcome is valid.

7. If useful, open **Prototype study** from the menu. Confirm that the response is saved only on this browser and does not modify the main plan. Use **Reset demo** afterward to restore seeded Plan A.
